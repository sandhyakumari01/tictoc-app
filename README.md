# 🎮 Tic-Tac-Toe React App

Welcome to the **Tic-Tac-Toe React App** — a fun and interactive two-player game built with **React.js**. Players take turns marking spaces in a **3x3 grid** to achieve victory.

## 📌 Features

- 🎯 Two-player turn-based gameplay  
- 👤 Dynamic player names and symbols  
- 🏆 Winning animations and game-over screen  
- 🤝 Draw detection system  
- 📱 Responsive design for all devices  
- ✨ Clean and interactive UI  

---

## 🎮 Game Rules

- The game is played on a **3x3 grid**
- Players take turns selecting an empty square
- One player uses **X** and the other uses **O**
- First player to align **3 symbols in a row** wins:
  - Horizontal
  - Vertical
  - Diagonal
- If all cells are filled and no winner is found, the game ends in a **Draw**
